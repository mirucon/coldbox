# 2026-10-21 source upkeep decisions

The owner authorized bounded maintenance for occasional existing users, with
minimal owner involvement. Source maintenance was authorized; WordPress.org
publication, release creation and dist-branch updates were deferred.

AMP rendering, Universal Analytics, Pocket, share counts and TGMPA were retired.
Old Coldbox article `?amp=1` links redirect to ordinary pages. Saved values for
retired settings were left intact. Ads promotion and support solicitations were
removed; ordinary Ads extension hooks and opt-in jQuery deregistration remain.

The theme build moved to plain CSS and esbuild. Feedly/Hatena retain their SVG
shapes and one-em sizing without an icon-font generator. The Add-on uses a copy-only
packaging script. Native WordPress/PHPUnit and database tests were retained.

The agreed support target was WP 7.0/7.1 patches, PHP 7.4 through 8.5, and the latest
two releases of Chrome, Edge, Firefox and Safari, including iOS. IE and Opera Mini
were excluded. This records the decision, not a guarantee that every version
was individually tested; maintained commands and CI coverage are in MAINTENANCE.md.

Surviving gettext keys were preserved. After a separately approved publication,
the owner requested that the agent revise necessary translations in all supported
locales and submit them to WordPress.org. Recheck locale availability at that time.
No translation submission or publication was performed as part of this upkeep.
